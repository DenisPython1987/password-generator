# Gerador de Senhas

Esse programa rodar em três vias:
  + Instalador
  + Terminal
  + Gui
    
## Gerador pelo terminal

O arquivo "gerador_terminal.py" roda o programa pelo terminal.

## Gerador pelo instalador

O arquivo "gui_gerador" dentro da pasta "dist" é o instalador do programa.

>[!IMPORTANT]
>O instalador só foi testado no Linux Ubuntu, não há informações de segurança para instalação
>em outros sistemas operacionais.

## Gerador Gui

Outra forma de utilizar o programa é gerar o gui executando diretamente o script "gui_gerador.py"
